# Simple Notes App

A simple and practical app for storing your daily notes.

## 📝 Description

This is a simple Android application built with Kotlin for storing notes. The main goal is to provide a quick and easy way to manage notes that you use every day. The backend logic is designed to be platform-independent, allowing for future expansion to other platforms. User authentication is handled through Google Sign-In.

## ✨ Features

*   **Google Sign-In:** Secure and easy login with your Google account.
*   **Create & Edit Notes:** Quickly add new notes or update existing ones.
*   **Simple Interface:** A clean and intuitive user interface for a seamless experience.
*   **Cross-Platform Ready:** The backend logic is separated, making it easier to adapt for other platforms.

## 🛠️ Technologies Used

*   **Frontend:** Kotlin for Android
*   **Authentication:** Google Sign-In

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

*   Android Studio
*   A Google account for the Sign-In feature

### Installation

1.  **Clone the repo**
    ```sh
    git clone https://github.com/your_username_/Project.git
    ```
2.  **Open in Android Studio**
    *   Open Android Studio and select `Open an Existing Project`.
    *   Navigate to the cloned repository and click `OK`.
3.  **Configure Google Sign-In**
    *   You will need to set up a Firebase project and add your `google-services.json` file to the `app/` directory.
    *   Follow the official documentation to get your SHA-1 key and configure Google Sign-In: [https://developers.google.com/identity/sign-in/android/start-integrating](https://developers.google.com/identity/sign-in/android/start-integrating)
